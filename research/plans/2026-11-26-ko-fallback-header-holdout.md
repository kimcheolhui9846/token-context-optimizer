# 한국어 합성 표의 머리글 보완 실험 사전등록

## 질문과 자료

W1 화면에서 질문한 행 이름과 두 값은 남고 두 열 제목이 사라진 경우, 고정된 OCR 결과로 찾아낸 머리글을 다시 붙이면 올바른 두 열 이름과 값이 같은 가로 위치에 표시되는가? 다른 행이나 별도 기록의 수치가 새로 노출되는지도 함께 센다. #157의 일곱 사례는 설계 배경이다. 실험 자료는 공개 목적으로 새로 작성한 표 18개이며 사람의 판독, API 청구 비용, 모델 정확도와 제품 동작은 측정하지 않는다.

- 기준 커밋은 `8200c01fd2bb14e8b2463bd3e4b2a418c6ed0157`이다. #155에 고정한 OCR·K1·W1·W4·W5 및 렌더러를 사용한다. 자료 목록, 결정 함수, 합성·채점 코드와 시험을 담은 첫 커밋을 잠근 뒤 새 자료의 렌더링과 OCR을 시작한다. 실행기는 잠금 커밋과 작업 사본을 대조한다. 한글 글꼴, OCR 언어 파일, 엔진 버전의 핀은 [기존 등록값](../tools/ko-blind-reader/registered.json)을 따른다.
- 시각·인원·분량 각 6표, 서로 다른 행 이름 54개를 사용한다. 유형 안의 순번 k=0–3은 정상, 4는 질문한 제목의 중복, 5는 질문한 제목의 부재다. 짝수 k는 왼쪽 열·두 번째 행, 홀수 k는 오른쪽 열·세 번째 행을 묻는다. k=1·2·4·5에서는 본문을 아래로 112px 옮기고 나머지는 기본 높이를 쓴다. 좌우와 행 깊이는 이 설계에서 결합되어 있다. 입력은 고정된 명단과 산식으로 생성하며 재추첨은 없다. #150–153의 공개 자료와 #155 공개 모의 자료에서 완전 일치하는 행 이름·질문 및 PNG를 검사한다. 과거 비공개 판독지는 사용하지 않는다.
- 세 유형의 k=2와 시각·분량 k=4, 인원 k=5에는 별관 기록의 수치를 표 상단에 놓는다. 별관 이름 셀은 [530,60,615,100], 그 값 셀은 [530,104,615,144]다. 두 제목은 왼쪽 [360,104,520,144]와 오른쪽 [620,104,840,144] 안에 렌더된다. 두 제목이 들어가는 수평 창에는 별관 숫자의 x좌표도 들어간다. 별관 이름이 OCR 제목 후보 그룹으로 읽혔는지와 별관 숫자가 실제 합성 띠에 들어갔는지를 문항별로 기록한다. 모든 셀의 페이지 경계와 실제 글자 영역을 점검한다.

## 고정 표시 규칙

W6는 #153 예측의 파싱된 질문 필드와 OCR 진단, #154 화면 조각, 원본 픽셀만 쓴다. 문항 번호, 실제 열·정답, 정답 상자와 사례 유형은 판정 입력에서 제외한다. W5가 W1을 그대로 반환한 매치에서만 적용한다. 자격이 있는 OCR 행이 하나이고 그 행의 세 그룹(행 이름 제목, 왼쪽 제목, 오른쪽 제목) 중 뒤의 두 그룹에서 질문 필드와 정확히 한 그룹만 일치해야 한다. #153과 같은 NFKC·공백 제거를 쓴다. 세 상자가 W1 폭 안에 있어야 한다. 세 상자의 최소 위끝을 내림하고 최대 아래끝을 올림한 후 양쪽에 6px을 더하고 페이지에 맞춰 자른다. 띠의 아래끝이 W1의 위끝을 넘으면 W5를 유지한다. 이 판정은 별관 기록의 정답 위치나 다른 행의 값을 사용하지 않는다.

적용 시 W1과 같은 x·너비로 원본 머리글 띠를 자르고 회색 구분선 8행 뒤에 기존 본문을 그대로 붙인다. 원본 픽셀을 재배율하지 않는다. W4를 적용했던 기존 W5 결과와 조건을 만족하지 않는 화면은 그대로 보존한다. upstream 오류·미매치는 분모에 남기고 결과 이미지가 없음을 표시한다. 파일 출처나 픽셀 무결성 오류는 실험 실행 오류다.

## 사전에 정한 지표와 판단

- 주 분모는 전체 18표, 정상 12표, 음성 대조 6표다. 그 안에서 정상 제목, W1 폴백, 매치, 행과 두 값 온전, 두 제목 잉크 모두 부재를 충족한 표를 ‘복원 기회’로 정의한다. 복원은 목표·경쟁 제목과 두 값, 행 이름 모두 온전히 표시되고 실제 제목과 원본 열의 좌우 대응이 유지된 경우다.
- 원본의 글자 상자에서 회색값이 255보다 작은 픽셀을 센다. 잘린 영역은 반열림 좌표로, 여러 조각은 원본 좌표에서 합집합으로 처리한다. 구분선은 글자가 아니다. 다른 행의 **양쪽 수치** 및 별관 수치를 전수 조사한다. 이미 일부 보였던 값에 추가된 픽셀도 새 노출로 세고 새로 전부 보인 항목을 별도 집계한다. 완전했던 단서의 손실, 잘못 적용한 음성 대조, 기준 대비 출력 면적 증가(원본 페이지 대비 %p, 구분선 포함)를 보고한다.
- 다른 값의 신규 잉크나 잘못된 적용·단서 퇴행이 있으면 안전성 실패다. 이외에는 기회 없음, 미복원, 불충분을 구분한다. 제한적인 긍정 판정에는 복원 기회가 적어도 하나 있고 전부 복원, 미표시 없음, 퇴행·잘못 적용·새 노출 없음, 실제 별관 스트레스 평가가 필요하다. 별관 숫자가 실제 적용 띠와 겹친 건이 0이면 해당 안전성은 미검증으로 남긴다. 이 설계에서 원래 가려진 별관 숫자를 띠가 실제 포함하면 노출 기준이 실패하므로, 이 시험만으로 안전 채택을 확정할 수 없다.
- 독립 검산에서는 모든 화면의 픽셀·상태, 다른 기록의 신규 노출, 분모와 면적을 재계산한다. 보고할 때는 기회와 미적용 사유, 스트레스의 실제 발생을 구분한다. 같은 규칙과 자료에서 실패한 경우도 보존한다. 결과를 본 뒤 규칙·라벨·자료를 바꾸지 않는다. 데이터·코드를 바꿔야 하는 후속 작업은 다른 실험이다.
