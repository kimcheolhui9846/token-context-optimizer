## 1. 질문과 가설

RQ3: 다중 턴 에이전트 세션에서 원본 보존 발췌(플러그인)는 전체 유지와 compact에 비해 누적 청구 토큰과 과제 정확도를 어떻게 바꾸는가?

| 가설 | 비교 | 판정 기준(사전 고정) |
|---|---|---|
| H1 | S2 대 S0 | 세션 평균 내용 정확도 차이(S2−S0)의 95% 신뢰구간 하한이 −5%p보다 크고, 정가 기준 입력 토큰이 S0보다 적다 |
| H2 | S1 대 S0 | 늦은 회상 정확도 차이(S1−S0)의 95% 신뢰구간 상한이 0보다 작다 |
| H3 | S3 대 S1 | 늦은 회상 정확도 차이(S3−S1)의 95% 신뢰구간 하한이 0보다 크다 |
| H4 | 캐시 기준 대 정가 기준 | S2의 캐시 기준 비용 절감률이 정가 기준 절감률보다 작다(기술 통계로만 보고, 검정 없음) |

margin −5%p는 2026-10-15 사용자 승인 기본안이다. 이 문서의 승인으로 확정한다.

## 2. 데이터

- held-out 24세션 = 템플릿 3종 × 8. 각 템플릿에서 기존 레이아웃 4세션, **held-out 전용 새 레이아웃 변형** 4세션.
  - 새 변형은 2026-10-15 사용자 결정(템플릿당 변형 하나)에 따른다.
  - 변형은 요소 배치, 글자 크기 분포, 표·카드·범례 위치를 바꾼다. 질문 유형과 정답 생성 규칙은 같다.
  - 변형 구현은 이 문서 확정 전에 끝내고, 생성 결과(manifest SHA-256)를 이 문서에 적는다.
  - held-out manifest `out/sessions/heldout/sessions.json`(`node src/sessions.mjs --split heldout`, 재생성 시 동일) SHA-256: `b88f64e3df671fff20a8562f7fbe1ba929b94f56d842e452b72d0cfb979d5da2`
  - 변형 이미지는 어떤 모델에도 미리 보내지 않는다.
- seed는 7000번대다. 개발(5000번대), calibration(6000번대), 파일럿 세트와 겹치지 않는다.
- 결과는 "기존 레이아웃"과 "새 레이아웃"으로 나눠서도 보고한다. 새 레이아웃 결과가 처음 보는 배치에 대한 성능 추정이다.

## 4. 공급자

- **주 분석:** `gpt-4o-2024-11-20`
- **보조 분석:** `claude-haiku-4-5-20251001`
  - 세션 하네스의 Anthropic 도구 사용 경로(공식 SDK)를 구현하고, 개발 세트로 점검한 뒤 동결한다. 점검 결과를 보고 Haiku의 compact 일정과 도구 상한을 바꾸지 않는다.
  - Haiku에서는 detail 설정이 없다. 썸네일은 긴 변 512 이하로 줄인 이미지 자체로 보낸다(patch 회계상 512×384 기준 19×14 = 266토큰). 이 차이를 보고한다.

## 5. 지표와 분석

- 주 지표: 세션 평균 내용 정확도. 보조: 늦은 회상·교차·요지·즉시 정확도, 정가 기준 입력 토큰, 캐시 기준 비용, 호출 수, 임계값 초과 턴 수, UNREADABLE 수, 원본 재요청 수
- 분석 단위는 세션(24개)이다. 모든 조건을 같은 세션에 적용하므로 세션 단위로 짝지어 차이를 계산한다.
- 신뢰구간은 세션 단위 bootstrap으로 계산한다(10,000회, seed 20261015, percentile 95%).
- 가설은 위 4개뿐이다. 그 밖의 비교는 탐색 결과로 표시한다.
- 실패와 타임아웃은 오답으로 센다. 실행하지 못한 세션은 `not_started`로 따로 보고하고, 완료 연구로 보고하지 않는다.
- 캐시 기준 비용은 공급자가 보고한 캐시 토큰과 확인된 공식 할인율로 계산한다. 할인율을 확인하지 못하면 가정값과 함께 [검증 필요]로 보고한다.

## 6. 하지 않는 것

- held-out 결과를 보고 설계·채점 규칙·margin을 바꾸기. 바꿔야 한다면 새 held-out 세트로 다시 등록한다.
- 세션 제외. 오류가 난 세션도 분모에 남긴다.
- 제품 compact(Claude Code, Codex)의 성능에 대한 주장. 이 실험의 compact는 공개 규칙으로 재현한 모사다.
