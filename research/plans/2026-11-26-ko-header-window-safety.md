# 머리글 두 칸과 전체 폭 띠 비교 사전등록

## 표본과 질문

기존 표의 질문 행, 두 값, 열 제목의 위치는 그대로 두고 다른 기록의 숫자를 머리글 가까이 놓는다. W5에서 그 숫자가 가려져 있어도 전체 폭 머리글을 붙일 때 드러나는가? 두 제목에 해당하는 가로 범위만 붙이면 원래 위치의 다섯 단서를 보존하면서 이 노출을 막을 수 있는가?

#158의 고정 커밋 `221db060ecbc44ae9ff61ab5df9c0dfe73d2baf2`에서 두 열 제목이 복원된 시각 질문 1·2·4번을 사용한다. 독립적인 원본은 세 장이다. 각 원본마다 무변경 대조 한 장과 4개 변형을 사용한다. 신뢰구간, 모집단 복원율, 인간 정확도는 추정하지 않는다.

| 변형 | 별관 값 셀의 왼쪽 x | 위쪽 y |
|---|---:|---:|
| 제목 사이, 같은 높이 | 530 | 104 |
| 오른쪽 여백, 같은 높이 | 990 | 104 |
| 제목 사이, 아래로 18px | 530 | 122 |
| 오른쪽 여백, 아래로 18px | 990 | 122 |

셀은 폭 80·높이 40픽셀이다. 별관 이름은 같은 x, y=30..70에 둔다. 값은 원본 순서대로 87·89·91이다. 원본 PNG 위에 고정한 R09 글꼴·가로 여백·앵커로 원본 크기의 독립 글자 레이어를 그린다. 대조는 #158 PNG를 그대로 복사한다. 별관 값과 이름의 잉크는 이 레이어에서 센다. 원본과 바뀐 픽셀의 위치, 원본 잉크와의 중첩, 페이지·셀 경계, 대조 W5·전체 띠·양쪽 제목 범위와의 겹침을 새 OCR 전 점검한다. 유효 배치는 원본 잉크와 추가 글자 중첩 0, W5의 별관 값 잉크 0, 전체 띠의 별관 값 잉크 양수, 두 제목 창의 별관 값 잉크 0을 충족한다. 잘못된 배치도 유지하며 재배치하지 않는다.

## 두 비교

1. **실제 OCR**은 15장 각각에서 #158과 같은 차단된 로컬 OCR·예측·W5를 실행한다. 질문과 렌더링된 PNG만 선택기에 전달한다. 기존 W6 결정이 거부되면 두 팔 모두 W5를 그대로 쓴다. 적용되면 기존 전체 폭 띠와, 같은 띠에서 자격 있는 유일한 행의 두 제목 그룹(0부터 센 1·2번)만 남긴 화면을 비교한다. x의 왼쪽은 내림 후 4px, 오른쪽은 올림 후 4px 확장하고 띠 경계에서 자른다. 겹치는 창은 합친다. 나머지 헤더는 흰색이다. 두 팔의 폭·높이·제목 x 위치·8행 구분선·본문은 같다.
2. **위치 고정 비교**는 같은 원본의 무변경 대조에서 새로 얻은 결정과 좌표를 변형에 고정하고 변형 자체의 픽셀을 조립한다. OCR이 새로운 숫자를 감지해 결정을 바꾸는 경로를 제외한 기하학적 비교다. 두 비교의 분모를 합하지 않는다.

## 집계와 판정

원본별·조건별 W5와 양쪽 화면에서 행 이름, 두 제목, 두 값의 총/가시 잉크를 비교한다. 다른 행의 양쪽 수치와 별관 값은 일부만 추가로 보여도 신규 노출이다. 별관 이름은 별도 진단으로 센다. W5나 전체 띠에서 완전하던 대상 단서를 두 칸에서 잃거나 어느 다른 기록의 수치 잉크든 추가되면 위해 관측으로 판정한다. 화면의 좌표와 원본 본문 픽셀은 재조립으로 검산한다.

유효 위험 사례는 배치 점검과 대조 재현을 통과하고, 실제 해당 방식이 적용됐으며, W5에 두 제목과 별관 숫자가 없고 행과 두 값은 온전하며, 전체 띠가 별관 숫자의 잉크를 새로 보여준 표다. 두 칸에서 다섯 단서가 모두 완전하고 모든 다른 값의 신규 잉크가 0이면 해당 위험 사례를 보호한 것으로 센다. 위해가 우선한다. 미표시·잘못된 배치·대조 불일치가 있거나 유효 위험 사례가 0이면 전체 판정은 미확정이다. 이외에 유효 위험 사례가 하나 이상이며 모두 보호되고 위해가 없을 때만 제한된 존재 시연으로 판정한다. 대조에는 #158의 두 제목·세 본문 단서 계수, W5·전체 띠의 픽셀 해시와 띠 좌표를 대조한다.

실험 코드와 이 문서의 커밋을 원격에 올린 다음 첫 OCR을 실행한다. 입력과 출력 누락, 잘못된 해시, 화면 무결성 오류는 실행 오류로 기록한다. 별도 새 디렉터리에서 원본부터 반복하고 공개 산출물을 바이트 비교한다. 결과를 보고 좌표·코퍼스·기준을 조정하지 않는다.
