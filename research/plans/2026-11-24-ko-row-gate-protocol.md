## 2. 질문과 해석 한계

#151의 무조건 세로 제한 W2는 W1이 보존한 답 48개 중 6개를 잘랐고, 답이 표지와 같은 줄인 24쪽에서는 손실이 없었다. 실제 예측 때에는 답의 배치를 알 수 없다. 이번 실험은 **질문이 요구하는 형식과 OCR 단어 좌표만으로** 표지와 같은 행의 답 후보가 유일한지 보고 W2 적용 여부를 정하는 규칙 W3 하나를 **새로 만든 48쪽**에서, 같은 OCR·같은 K1 선택 기록·같은 W1·W2로 한 번 비교한다. 후보가 실제 답이라고 가정하지 않는다.

- **일차 비교 W1→W3**, 참고 비교 W1→W2(같은 쪽, 같은 분모). 답변 정확도·토큰·비용은 재지 않는다. 면적은 픽셀 면적이다.
- 자료는 12개 문서 원본 × 4배치의 짝지은 설계다. 관찰 단위는 페이지지만 같은 원본의 4쪽은 질문·답·레코드 텍스트를 공유하므로 48개 독립 사례가 아니다. 결과는 이 합성 분포와 고정 O1 OCR에 대한 **기술 통계**다. 추론 검정·신뢰구간·일반화·상위 그룹 인과 주장을 하지 않는다.
- **설계상 반례가 들어 있다.** "답 아래 줄 / 방해 값 표지 줄"(below-same) 배치에서는 표지 줄에 같은 형식의 방해 값 하나만 남는다. 이상적인 인식이면 W3는 이 유일한 후보를 보고 W2를 적용해 아래 줄의 답을 잃는다(3.4절 예측표). 이 배치는 요청서가 요구한 필수 배치이며, "후보 한 개"가 틀릴 수 있음을 측정하기 위한 것이다. 결과에 맞춰 빼거나 바꾸지 않는다.
- #150·#151의 페이지와 수치는 기댓값·통과 조건이 아니며 합산하지 않는다. 매개변수 탐색, 사후 예외, 골드를 이용한 복원, 제품 통합은 하지 않는다. 양성 결과도 제품 기본값 채택과 다르다.

- 값 문법(형식): time `H:MM`/`HH:MM`(시 9–20, 분 10분 단위), count `N명`(8–95), pages `N쪽`(12–240). 질문: time `{표지}의 {항목}은 언제인가요?`, count `… 몇 명인가요?`, pages `… 몇 쪽인가요?`. 항목명(문서 종류 × 유형): lecture 개강 시각/종강 시각, 신청 인원/대기 인원, 교재 분량/부록 분량; exhibit 해설 시각/집합 시각, 예약 인원/현장 인원, 자료 분량/도록 분량; meeting 개회 시각/휴회 시각, 참석 인원/배석 인원, 배부 분량/예비 분량(앞 = 질문 항목, 뒤 = 방해 항목).
- 정답 = 목표 레코드 지정 값 텍스트. 골드 두 상자 = 목표 표지 item과 목표 값 item의 실제 잉크(고정 렌더러, 반열림 `[l, t, r, b)`).
- 정규화 질문(NFC, 양 끝 공백 제거, 내부 연속 공백 하나로)은 원본별 1개, 서로 다른 12개이며 각 4번 나온다. 같은 원본의 4쪽이 같은 질문·답·레코드 텍스트를 공유하는 대응을 실험과 보고에서 유지한다.
- 등록 설계 조건(생성기 `check`, 문제 0이어야 함): 12원본·48쪽·ID와 순서, 슬롯·유형 균형(3.1절), 짝 일치(원본 4쪽의 질문·답·표지·항목 id·역할·텍스트·x 좌표·셀 높이·슬롯이 같고 맞바꾸는 네 항목의 y만 다름), 질문에 목표 표지 정확히 1회, 질문에 ASCII 영숫자 없음(K0 정상 미매치 → 한글 분기), **질문 유형 판정(4.4절 1단계)이 design 유형 하나뿐**, 지정 값·방해 값은 그 유형 문법을 만족하고 그 밖의 모든 item 텍스트는 어떤 유형 문법도 만족하지 않으며 ASCII 영숫자가 없음, 한 쪽의 지정 값·방해 값 6개 서로 다름, 목표 표지 한글 bigram ≥ 4, 목표 외 어떤 item도 목표 표지와 bigram 공유 없음, 머리글·제목 외 item은 질문과 bigram 공유 없음, 머리글·제목은 질문과 공유 bigram ≤ 2, item 텍스트 쪽 안 유일, 각 셀이 등록 위치, 셀 겹침 없음, 셀·구분선 겹침 없음, (`--font`) 글꼴 측정 상자가 셀·인쇄 영역 안이고 3.2절 허용치 충족, 이상적 같은 행 후보(3.4절)가 배치별 예측과 같고 다른 레코드의 값·방해 값은 목표 표지 행에 없음.
- 한계(공개): 표에는 값 항목명이 머리글에 있으므로 K1이 머리글 줄을 고를 수 있다. 질문 유형 단서는 부분 문자열 검사이므로 일반 질문에서 "몇 시간"도 time으로 분류된다(이 자료의 12개 질문에는 해당 없음, 인계서에 한계로 적음).

### 3.4 이상적 인식의 기하 예측표와 기준 띠 (등록)

**가정:** OCR이 모든 항목을 한 단어(또는 문법을 지키는 인접 단어)로 정확히 읽고, K1이 목표 표지 줄을 고르며 히트가 목표 표지 단어이고, W1이 넓어져 W2가 실제로 자르며(`cut`), 다른 같은 행 후보가 없다.

| 배치 | 표지 행의 같은 형식 후보 | 이상적 W3 판정 | 이상적 결과 |
|---|---|---|---|
| same-same | 지정 값 + 방해 값 (2개) | `multiple_candidates` → W1 유지 | W2의 다른 값 제거 효과를 쓰지 않음, 손실 없음 |
| same-other | 지정 값 (유일, 목표 값) | 후보가 W2 안이면 `applied` → W2 | W2와 같음(손실 없음, 제거 효과 유지) |
| below-same | 방해 값 (유일, **의도된 방해**) | 후보가 W2 안이면 `applied` → W2 | **W2와 같이 아래 줄 답 손실**(설계상 반례) |
| below-other | 없음 (0개) | `no_candidate` → W1 유지 | W2 손실 예방 |

- 유일한 후보는 W2 안일 때만 적용한다. 실제 OCR·K1에서는 단어 분할, 오인식, 머리글 줄 선택, 히트 위치가 이 표와 다를 수 있다. 이 표는 기댓값이나 통과 조건이 아니라, 실제 결과와 비교할 사전 기하 설명이다.
- **기준 띠(참고용, OCR·예측과 분리):** 렌더 직후 목표 표지 잉크를 한 히트 단어로 놓고 W2 식(패딩 = 그 높이)을 적용한 세로 띠 `[floor(top − h), ceil(bottom + h))`에서, 목표 지정 값과 목표 방해 값 잉크의 세로 완전 포함 여부를 쪽마다 `checks.json`에 기록한다. 개발 중 글꼴 측정에서는 지정 값이 `ans = same` 24쪽에서만, 방해 값이 `dec = same` 24쪽에서만 띠 안이었다(아래 줄 항목은 모두 띠 밖). 이 띠는 결과에 맞춰 재생성·배제하지 않는다.

### 4.3 W0·W1·W2 (고정)

- W0 = 동결 K1 기록의 `band`(정상 매치일 때). W1 = 고정 #150 `w1Rule` 그대로. W2 = 고정 #151 `w2Rule(w1Rule, …)` 그대로(사유 `inherit`/`cut`/`no_cut`/`hit_outside_w1`). 예측 행의 K1 재계산 대조·ID 결합·이미지 해시 결합·W2 검증은 고정 #151 `buildPrediction`을 그대로 호출하고, W3 필드를 그 뒤에 덧붙인다.

### 4.4 W3 (등록 규칙)

`RECOUNT_SPEC.md` 4절이 정의다. 요약:

1. 오류·미매치는 그대로(`w3 = null`, 보류 사유가 아님). **W2가 W1을 실제로 좁히지 않았으면**(`w2Reason != "cut"`) `not_applicable`, W3 = W1.
2. 질문을 NFKC 정규화한 뒤 Unicode White_Space를 지운다. "시각" 또는 "몇시" → time, "몇명" → count, "몇쪽" → pages(부분 문자열, 같은 유형 중복은 한 건). 유형이 정확히 하나가 아니면 W1(`qtype_none`/`qtype_multiple`). 질문의 답이나 페이지 ID 목록은 쓰지 않는다.
3. H = 동결 `k1.lineIndex` 줄에서 `k1.hitWords`에 저장된 단어 중 유효 단어(유한 좌표, 너비·높이 > 0)만. 합치거나 하나를 고르지 않는다. 비면 W1(`no_valid_hit_word`, 정상 보류).
4. **W2로 자르기 전 전체 OCR**에서, 줄마다 원래 순서의 연속 단어 1–3개를 후보 단위로 열거한다. 무효·빈 단어가 끼면 그 구간은 버린다(건너뛰지 않음). 다중 단어는 이웃 간격 `0 ≤ gap ≤ min(두 높이)/2`(정렬 없음). 정규화 연결 문자열이 유형 문법에 전체 일치(time `^(?:[0-9]|[01][0-9]|2[0-3]):[0-5][0-9]$`, count `^[1-9][0-9]{0,2}명$`, pages `^[1-9][0-9]{0,2}쪽$`). **같은 행의 오른쪽**: 어떤 h ∈ H 하나가 구간의 모든 단어 u에 대해 `x0(u) ≥ x1(h)` 그리고 `2·max(0, 세로 겹침) ≥ min(height(u), height(h))`. 서로 다른 h가 각자 다른 단어만 지지하면 탈락. **합집합 상자 대안은 쓰지 않는다.** 줄 번호는 달라도 된다. (줄, 첫 단어, 끝 단어)가 같은 단위만 한 번으로 센다.
5. 후보 0개(`no_candidate`)·2개 이상(`multiple_candidates`)·1개지만 단어들의 최소·최대 좌표 상자 C가 W2에 완전히 들지 않음(`candidate_outside_w2`)이면 W1. **유일한 후보의 C ⊆ W2일 때만 W3 = W2**(`applied`).
- 모든 W3 좌표 비교는 동결 OCR의 **원래 JSON 수 표기를 정확한 십진 유리수**로 해석한다(부동소수점 덧셈 없음). W2 좌표는 고정 구현이 직렬화한 정수다. OCR 상자가 전부 정수면 그 사실과 정수 경로를 기록하고, 소수 경계는 손계산 예제(0.5 대 0.4999, 0.1 + 0.2)로 검사한다.
- W3는 항상 W1 또는 W2와 정확히 같고 새 창을 만들지 않는다. 사후 단언: `W3 ∈ {W1, W2}`, `W2 ⊆ W3 ⊆ W1`.
- 페이지별로 질문 유형, 유효 히트, 진단 후보 열거(후보 출처: 줄·첫/끝 단어 번호·원래 좌표 표기·연결 문자열·C·지지 히트), 결정 사유를 남긴다. 진단 열거는 적용 대상이 아닌 쪽(`not_applicable`)에서도 기록하지만 판정에는 4.4절 순서만 쓴다.
- **입력 제한:** W3 함수의 인자는 질문, 동결 OCR 줄(정확 표기), 동결 K1 기록, 고정 W2 결과뿐이다. 페이지 ID·문서 종류·양식·정답·렌더 위치·배치 이름은 인자가 아니며 판단에 쓰지 않는다(ID는 행 결합 키로만 쓴다). 시험이 함수 인자 수와 ID 치환 불변을 확인한다.

### 4.5 재생과 예측 동결

- 재생기 `node src/ko-row-gate-replay.mjs --ocr <ocr dir> --out <replay dir>`: OCR `freeze.json` 해시 확인 → 각 페이지 원시 OCR로 고정 `keyResults`를 다시 실행해 저장 K1과 같은지 확인(고정 `buildPrediction`) → 고정 W1·W2 → W3 → `predictions.jsonl` 48행, `freeze.json`, `inputs.json`(실제로 연 입력의 상대 이름과 SHA-256). 재생기의 자료 입력은 **허용 목록 리더**(선택기 측 `selector/questions.json`, `selector/images/*.png`)를 거친다. `scoring/`·`gold`·`design`·`render`·`score` 경로를 열려는 시도는 거부(예외)되며 시험으로 확인한다.
- 재생 A의 `predictions.jsonl`(W1·W2·W3 48행)을 커밋·push(예측 동결)한 **뒤에만** 채점기가 `scoring/`을 연다. 채점기는 예측 파일이 HEAD에 커밋된 blob과 같은지 기록한다.
- 재생 B: 별도 프로세스에서 같은 동결 OCR로 다시 재생·채점해 결정적 파일을 바이트·행 단위로 비교한다. OCR을 두 번 수행한 독립 실험이 아니다.

### 4.6 오류와 검증 실패

- 통상 OCR/선택기 기술 오류·타임아웃은 48쪽 분모에 남기고 모든 창에서 실패로 센다(`w3Reason "error"`). 미매치도 48쪽 분모에 둔다(`"unmatched"`). 기술 오류와 정상 보류(`not_applicable`, `qtype_*`, `no_valid_hit_word`, `no_candidate`, `multiple_candidates`, `candidate_outside_w2`)를 나눠 센다.
- 원본 해시·인덱스·키 손상·누락, 사전등록 위반, 결정적 재생 불일치, W3 사후 단언 위반, 허용되지 않은 회복은 **과제 검증 실패**다. 그 실행을 불완전으로 기록하고 손상 페이지를 선택적으로 빼지 않는다.

## 5. 채점과 보고 지표

`RECOUNT_SPEC.md` 5–6, 10절이 정의다.

- **엄격 성공**(#147 `scoreKey` 그대로): 정상 매치, `0 < 면적 < 페이지 면적`, 표지·값 두 잉크 전체 포함(여유 0). 창이 전체 페이지면 두 잉크를 담아도 실패. W1/W2/W3 각각.
- **전이**: W1→W2, W1→W3 각각 회복·손실·유지·둘 다 실패, ID별. **회복은 W1이 전체 페이지이고 비교 창이 부분 창이며 두 근거가 계속 완전히 포함될 때만 가능**하다. 실제 회복 행이 이 예외를 모두 만족하는지 단언하고 별도로 센다(`recoveredFullPage`). 손실 행은 잘린 근거(표지/값/둘 다)를 남긴다.
- **W2 손실 예방**: W2에서 잃었고 W3가 W1로 되돌려 보존한 쪽(`prevented`) / W2 손실 수.
- **일차 지표 L3**: W1 엄격 성공에서 W3 실패로 바뀐 쪽 수 / W1 엄격 성공 수(참고 L2도 같은 분모). 서로 다른 원본 수를 같이 쓴다. **L3 ID 집합 ⊆ L2 ID 집합**을 검증한다.
- **공통 기회 집합**: 매치 ∧ W1 엄격 성공 ∧ W2 `cut` ∧ W1 안에 다른 레코드 지정 값 하나 이상 완전 포함. 그 안에서 W1과 비교 창이 모두 엄격 성공이면서 W1에서 완전했던 다른 값 하나 이상을 비교 창이 완전히 제외(교집합 0)한 쪽 수를 W2(`event2`), W3(`event3`) 각각 센다. **event3 ⊆ event2**를 검증한다. W3가 유지한 W2 사건 수 / W2 사건 수(`keptEvents`). 대상 0이면 해당 없음.
- **다른 레코드 지정 값 노출**: W1에서 완전했던 값이 W2·W3에서 완전/일부/전혀(교집합 0, 맞닿음 포함)로 전이한 항목 수와 페이지 수.
- **유일 후보의 골드 분류(채점 측만):** 후보가 정확히 하나인 쪽마다, 후보 단어들의 중심이 모두 같은 한 텍스트 항목 셀(반열림, 카드 외곽·레코드 영역 아님)에 유일하게 배정되고 C와 그 항목 잉크의 교집합이 양수일 때만 그 항목으로 확정한다. 목표 값(`target_value`) / 의도된 방해 값(`intended_decoy`) / 다른 레코드 지정 값(`other_record_value`) / 기타·모호(`other_or_ambiguous`). 적용 여부와 무관하게 모든 유일 후보를 분류하고 잘못된 유일 후보 목록(`uniqueWrong`)을 낸다. 의미 인식이나 답변 정확도로 해석하지 않는다.
- **면적(부수 지표)**: W1 면적 − W2/W3 면적. 픽셀 합과 페이지 면적 대비 평균·중앙값·최대 %p를 유효 매치 전체와 실제 W3 적용 쪽 각각. 0분모는 `null`.
- **사유 표**: W3 사유 10개(error, unmatched, not_applicable, qtype_none, qtype_multiple, no_valid_hit_word, no_candidate, multiple_candidates, candidate_outside_w2, applied)의 배타 빈도.
- **분리 표**: 전체 48쪽, W2 `cut`, W3 `applied`, 배치 4조건, ans, dec, 양식, 문서 종류, 질문 유형, W3 사유별, **12개 원본 × 4배치 표**(원본별 4쪽 결과). 단계별 분모와 전이표를 표마다 명시한다. 형제 배치 수(48쪽)와 독립 원본 수(12)를 구분한다.

### 5.1 측정 전 해석 기준 (요청서 그대로, 등록)

- 입력 무결성과 A/B 일치가 전제다. 통상 OCR 오류가 하나라도 있으면 그 수와 분모 48을 표시하고 해석은 관찰 가능한 정상 쪽으로 한정한다. 입력을 다시 채우지 않는다.
- L3 > 0: 이 자료에서 "기존 성공을 잃지 않는다" 요건을 충족하지 못했다. 손실을 줄였어도(L3 < L2) 같이 기록한다.
- L3 = 0, 공통 기회 > 0, event3 ≥ 1: 손실 없이 다른 값을 제외한 성공 유지 사례가 관찰됐다. 한 원본에만 있으면 한 원본의 사례, 2개 이상이면 반복 관찰된 원본 수로만 기술한다. 통계적 지지나 채택 문턱이 아니다.
- L3 = 0이고 W3 적용 0 또는 공통 기회 0: 제거에 관한 판정 기회가 없었다("손실 0"과 함께 "실제 적용 0, 효과 평가 기회 없음"을 명시).
- L2 = 0이면 손실 예방 효과를 주장하지 않는다.
- 조건별 원빈도와 처리 오류를 병기한다. 같은 분자·분모 원칙을 배치 4조건에도 적용한다. 원본·조건 수가 적은 결과에 일반화·상위 그룹 인과 주장을 붙이지 않는다. 판정 코드(`verdict`: `loss3`, `loss2`, `prevention`, `removal`)는 `RECOUNT_SPEC.md` 6절 규칙으로 기계적으로 만든다. 연구 검증과 제품 채택은 별개(사용자 결정)다.
