| 묶음 | 목표 값 | 다른 레코드 값 | 그 값이 들어간 쪽 | 다른 레코드 표지 | 비고(무관 항목) | 머리글·항목명 |
|---|---|---|---|---|---|---|
| 전체 | 23 | 34 | 16 | 0 | 43 | 39 |
| inline / stacked | 20 / 3 | 32 / 2 | 14 / 2 | 0 / 0 | 37 / 6 | 34 / 5 |
| table / cards | 11 / 12 | 29 / 5 | 11 / 5 | 0 / 0 | 27 / 16 | 22 / 17 |
| near / far | 10 / 13 | 15 / 19 | 7 / 9 | 0 / 0 | 17 / 26 | 17 / 22 |

- 위 표는 **새로 담은 것만** 센다. W0 밖에 있다가 W1에 완전히 들어온 item만 포함하고, 이미 W0 안에 있던 item은 세지 않는다. 그래서 "다른 레코드 값 34개"는 W1 창 안의 다른 레코드 값 전체가 아니라 증가분이다. 넓힌 23쪽 중 16쪽이 다른 레코드 값을 새로 담았고(합 34개, 표 양식 29개), 오른쪽 무관 항목(비고)은 43개 새로 들어왔다.
- 같은 기준(렌더 잉크 상자가 창 안에 **완전히** 들어감, 목표 값 제외, 역할이 `value`인 item)으로 W0와 W1 각 창 안의 다른 레코드 값 **전체**를 직접 다시 셌다.

| 묶음 | W0 창 안 전체(개 / 쪽) | W1 창 안 전체(개 / 쪽) | W1에 새로 들어옴(개 / 쪽) | W0에만 있음 |
|---|---|---|---|---|
| 전체 | 16 / 11 | 50 / 27 | 34 / 16 | 0 |
| inline / stacked | 3 / 2 · 13 / 9 | 35 / 16 · 15 / 11 | 32 / 14 · 2 / 2 | 0 |
| table / cards | 16 / 11 · 0 / 0 | 45 / 22 · 5 / 5 | 29 / 11 · 5 / 5 | 0 |
| near / far | 12 / 8 · 4 / 3 | 27 / 15 · 23 / 12 | 15 / 7 · 19 / 9 | 0 |
| 전이별: 유지 22쪽 | 12 / 8 | 12 / 8 | 0 / 0 | 0 |
| 전이별: 회복 23쪽 | 0 / 0 | 34 / 16 | 34 / 16 | 0 |
| 전이별: 둘 다 실패 3쪽 | 4 / 3 | 4 / 3 | 0 / 0 | 0 |

- W1 ⊇ W0이므로 W1 전체 50 = W0 전체 16 + 새로 들어옴 34이고, W0에만 있는 값은 0이다. PM 독립 값(W0 11쪽 16개, W1 27쪽 50개)과 일치한다. 다른 레코드 값은 W1 이전에도 W0의 16개(11쪽, 모두 표 양식)에 이미 있었다. W1은 이를 50개(27쪽)로 늘렸다.
- 이 수는 **완전 포함**만 센다. 창 경계에 일부만 걸친 값은 어느 열에도 들어가지 않는다. 그런 값은 따로 세지 않았다. 또 창 안에 다른 값이 있다는 것은 혼동 가능성일 뿐이다. 실제 답변에서 다른 레코드 값을 고른 오류(답 선택 오류)는 측정하지 않았다(답변 생성 없음). 둘은 위 수와 별개의 미측정 항목이다.

## 7. 사후 관찰 (동결 K1 기록의 기술, 규칙·판정 변경 없음)

- inline 24쪽 중 20쪽은 K1 선택 줄이 고정 선택기의 `axisRow` 조건(단어 ≥ 8, 평균 길이 ≤ 4, 앵커 폭 < 줄 폭 25%)에 들어 W0가 앵커 주변 좁은 세로 열이었다. W0 실패 inline 21쪽 중 20쪽은 근거 하나만(`partial`) 담았다.
- stacked 24쪽 중 18쪽은 선택 줄이 목표 표지와 같은 행의 비고까지 한 OCR 줄로 묶여(줄 오른쪽 끝 1,126–1,153px) W0가 이미 페이지 오른쪽 끝(1,280px)까지 닿았고 아래로 6줄 높이를 덮어 18쪽 모두 W0로 성공했다. 나머지 6쪽은 `axisRow` 줄 3쪽(모두 W1로 회복), 머리글 줄 2쪽(둘 다 실패), 카드 캡션 줄 1쪽(W0 성공 유지)이다. 그래서 stacked에서 W1의 추가 기여가 작았다.
- 따라서 이번 회복의 대부분은 "값이 오른쪽 밖"이라는 #149 관찰 그대로라기보다, 짧은 단어가 많은 OCR 줄에서 고정 선택기가 세로 열 창을 고른 경우를 W1이 같은 행 오른쪽으로 넓혀 보완한 것이다. 이 구분은 사후 관찰이며 원인 판정이 아니다(OCR 줄 분할과 창 형태가 섞여 있다).
