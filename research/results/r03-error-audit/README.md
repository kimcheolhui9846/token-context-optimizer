# R03 저장 응답과 압축 요약의 오류 감사

실험 3 held-out의 저장 응답 **60개**에서 두 판정자는 확정 정답 45개, 명시적 유보·판독 불가 8개, 유보 없는 확정 오답 7개를 기록했다. 압축 요약 **24개**에서는 바로 앞 답변의 목표 사실을 평가할 수 있던 22개가 모두 그 사실을 보존했다. 앞선 답변이 정답을 명확히 제시하지 못한 2개는 평가 불가였다. 이는 한 요약당 사실 하나에 대한 결과다.

## 표집과 최초 판정

기준 입력은 `f04d4b69083c0d1446a8b3ac760f185a1204cea9`의 `research/results/s3-heldout/`이다. 모집단은 응답 1,920개와 요약 192개다. [동결 코드북](../../plans/2026-11-20-r03-codebook.md)과 `prepare.py`, 실제 영문 문안 `rating.py`를 판정 전 커밋 `7296f649e0626c8f7fad31e2bd0c150ddd78aa12`에 고정했다. 응답은 30개 층에서 서로 다른 세션 2개씩(60/1,920, 3.125%), 요약은 24개 층에서 1개씩(24/192, 12.5%) 골랐다. 표본과 각 판정자의 제시 순서는 공개 해시로 정했다.

| 판정자 | 모델과 실행기 | 최초 유효 판정 | 호출 수 |
|---|---|---:|---:|
| Anthropic | `claude-sonnet-5-5`, Claude CLI 2.1.328 (Claude Code) | 84 | 7 |
| OpenAI | `gpt-6.2-sol`, codex-cli 0.170.0 | 84 | 6 |

Claude의 모델 ID는 응답의 `modelUsage`에서 확인했다. OpenAI는 도구 없는 확인 요청에서 CLI가 출력한 제공자·모델을 확인하고 각 판정 요청에서 같은 모델 ID를 지정했다. 두 판정자는 빈 디렉터리의 새 세션에서 같은 표본을 서로 다른 순서로 받았다. 질문·허용 정답·실제 답과 요약 판정에 필요한 요약문만 보냈다. 조건·제공자·세션·시점·기존 채점·종료 사유·상대 판정은 보내지 않았다. Claude 도구는 비활성화했고 OpenAI 실행 이벤트에서 도구 사용은 0건이었다. Claude 첫 배치의 한 행은 허용된 네 필드 외에 `kind`를 추가해 스키마 검사를 통과하지 못했다. 유효 13건을 고정하고 해당 ID 한 건만 재요청했다. 두 제공자의 최종 유효 기록은 168건이며 원실험의 답이나 요약을 새로 생성한 횟수는 0건이다.

| 판정 축 | 대각선 도수(Claude = OpenAI) | 일치 / 비교 |

| 응답의 육안 절단 흔적 | present 1, absent 59, unclear 0 | 60/60 |
| 요약 주분류 | retained 22, unassessable 2. omitted·contradicted 각 0 | 24/24 |

네 교차표 모두 비대각선 도수는 0이었다. 조정할 사례가 없어 [조정 기록](adjudication.json)은 빈 배열이다. [Claude 최초 판정](claude.json)과 [OpenAI 최초 판정](openai.json)에 판정 근거, 시도별 응답 원문과 입력·출력 SHA-256이 남아 있다. [항목별 결과](audit.csv)는 블라인드 ID를 원본 파일·턴, 두 최초 판정 및 최종 분류와 연결한다.

## 요약의 종료 사유와 텍스트 절단

전체 192개 요약을 완료된 세션 결과의 `attemptId`, 세션, 조건, 턴에 맞는 compact 호출과 대조했다. GPT-4o 종료 사유는 S1과 S3에서 각각 48/48개가 미기록(`unknown`)이다. Haiku에서 `max_tokens`는 S1 24/48개, S3 1/48개였고, 나머지 S1 24개와 S3 47개는 `end_turn`이었다. 아래 표는 그중 **판정 표본 24개**의 교차표다.

| 기록된 종료 사유 | 텍스트 절단 present | absent | unclear | 표본 수 |
|---|---:|---:|---:|---:|
| max_tokens | 2 | 1 | 0 | 3 |
| end_turn | 0 | 9 | 0 | 9 |
| unknown | 0 | 12 | 0 | 12 |

종료 사유가 누락된 사례는 문장 끝이나 길이로 보충 추정하지 않았다. 텍스트에서 관찰된 절단 흔적은 표현 상태에 대한 판정이다. 종료 원인이나 원자료 전체의 정보 손실을 판별하는 검사가 아니다.

## 재현과 해석 범위

저장소 루트에서 Python 3.10 이상과 Git으로 아래 명령을 실행한다. 제시 자료, 판정 원문에서 잠근 첫 유효 행, 조정 적용, 84개 CSV 행과 요약을 다시 대조한다. 모델 접속은 필요 없다.

```sh
python research/results/r03-error-audit/prepare.py
python research/results/r03-error-audit/verify.py --json
```

판정자에게 제공자·조건 필드를 숨겼어도 문체·길이·도구 명칭이 출처를 암시할 수 있다. 수집의 Haiku, 판정의 Sonnet, 검토의 Opus는 모두 Anthropic 계열이다. GPT-4o 수집과 Sol 판정도 OpenAI 계열이며, 사람 판정과 별도로 대조하지 않았다. 표본의 일치는 정확성의 독립 증명이 아니다. 같은 세션과 질문이 조건 사이에 반복될 수 있으며 오류 유형을 기준으로 표집하지 않았다. 전체 오류율, compact의 인과 효과, 실제 제품 성능 또는 원논문의 새 정확도 추정에는 이 결과를 사용하지 않는다.
