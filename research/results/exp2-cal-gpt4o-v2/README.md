## 점검과 관찰

- **재요청 경로 확인.** Haiku의 재요청 3건 모두 첫 답에 UNREADABLE이 있었다.
  - 배정 variant를 변환 없이 보냈다. 예: `variants/…/downscale-only.png`
  - 최종 답은 두 번째 답이고, 토큰은 합산됐다. 예: 200 + 1,096 = 1,296
- **GPT-4o: D와 C의 정오가 48 slot 모두 같았다**(D−C 0.0).
  - 답 문자열은 44/48이 같았다. 다른 4건은 모두 두 호출 다 틀린 작은 글자 문항이다(예: "1178" 대 "1187"). temperature 0에서도 독립 호출의 답이 완전히 같지는 않다.
  - UNREADABLE은 0회였다. GPT-4o에서는 응답 기반 재요청이 한 번도 작동하지 않았다.
- **Haiku: D가 C보다 낫다(+6.3%p).** D와 C의 정오가 다른 slot은 3개뿐이고, 정확히 재요청 3건(stress 조건)이다. 3건 모두 재요청으로 오답이 정답이 됐다. Haiku에서는 응답 기반 재요청이 작동했다.
- **옛 규칙(Dp)이 GPT-4o에서 가장 높다.** 이득은 전부 "창 없음 → 원본"에서 왔다. 개정 프로토콜은 이 규칙을 두지 않는다(Task 34 Q2 사용자 결정). Dp는 탐색 arm으로만 보고한다.
- 조건별(GPT-4o): clean·JPEG-only에서 D = C = A. stress 조건(1024 축소)에서 D가 A보다 8%p 낮다. Dp는 모든 조건에서 A 이상이다.
