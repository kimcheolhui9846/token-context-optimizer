## 1. #141 재생 대조 (p = 0): 통과

- 48개 ID 모두 #141 `rgb|tolerant|region` 행과 같았다: 요청 좌표, 반환 종류(부분 JPEG 36, 검증된 원본 12), 반환 구간, 포함 판정(complete 47, #141 partial ↔ incomplete 1)
- 원본 치수: #141 RGB 색인 응답, #141 RGB manifest, 새 gray8 색인 응답, 배정 `page`가 48개 모두 1280×960으로 같았다(같은 좌표계)
- 미매치 12개의 요청·반환은 모두 `[0, 0, 1280, 960)`이다
- #141 RGB manifest의 파생 출처 SHA가 새 입력 원본 SHA와 48개 모두 같았다. 표현 간 SHA는 비교하지 않았다
- 따라서 아래 p > 0 결과는 #141 사례와 같은 좌표·같은 판정 기준에서 직접 비교할 수 있다

## 4. 해석

- 이 자료에서 관측한 2px 손실은 대칭 여백 4px로 복구되었고, 매치 행의 평균 전달 면적은 페이지의 0.85퍼센트포인트 늘었다. 8px·16px도 포함 결과는 같았고 면적만 더 늘었다
- 이것은 이미 알려진 한 사례의 재생이다. 다른 문서·다른 선택기·다른 글꼴에서 같은 여백이 충분하거나 필요하다는 근거가 아니다. 판독성·정답률은 재지 않았다
- 제품 기본 여백은 정하지 않는다. 기본값 논의에는 새 자료의 사전 등록 평가가 필요하다
