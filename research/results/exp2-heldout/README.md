## 1. 가설 판정

| 가설 | 비교 | GPT-4o | 판정 | Haiku | 판정 |
|---|---|---|---|---|---|
| **H1(primary)** | D−A, 하한 > −5%p **그리고** 토큰 D < A | −6.9%p [−15.3, 0.7]. 토큰 635 대 824 | **지지 안 됨** | −4.2%p [−13.2, 3.5]. 토큰 765 대 1,361 | **지지 안 됨** |
| H2 | D−C | +6.3%p [1.4, 12.5] | 기술 통계 | +9.0%p [2.8, 16.7] | 기술 통계 |
| H3 | C−B | −11.8%p [−22.9, −2.1] | 기술 통계 | −13.9%p [−25.0, −3.5] | 기술 통계 |

- H1
  - 두 공급자 모두 D의 입력 토큰이 A보다 적었다(GPT-4o −23.0%, Haiku −43.8%).
  - 그러나 정확도 차이의 95% 구간 하한이 −5%p보다 낮아 **사전 등록한 비열등 기준을 충족하지 못했다.** 비열등성을 입증하지 못했다는 뜻이며, −5%p 이상 열등하다는 입증은 아니다. 두 구간 모두 0을 포함한다.
- 사전 등록대로 설계·채점·margin을 바꾸지 않는다.

## 3. 재요청과 사전 등록 관찰 항목

| | GPT-4o | Haiku |
|---|---|---|
| D 재요청률(전체) | 11/144 | 16/144 |
| 조건별(원본 / JPEG / 1024 / 1024+JPEG, 각 36) | 2 / 2 / 4 / 3 | 3 / 3 / 5 / 5 |
| 재요청 뒤 정답 | 9/11 | 13/16 |
| D와 C의 정오가 다른 slot | 9(모두 D 정답·C 오답, 모두 재요청) | 13(모두 D 정답·C 오답, 모두 재요청) |
| UNREADABLE 응답 수: A / C / D 첫 호출 | 0 / 10 / 11 | 0 / 16 / 16 |

- **D−C 차이는 전부 재요청에서 왔다.** 재요청하지 않은 slot에서 D와 C의 정오가 다른 경우는 없었다. D가 C보다 나쁜 slot도 없었다.
- **사전 등록 관찰 항목(GPT-4o의 UNREADABLE).** calibration(12 family)에서는 0회였지만 held-out에서는 C 10회, D 첫 호출 11회였다. 응답 기반 재요청이 GPT-4o에서도 작동했다. 다만 C 오답 40건 중 UNREADABLE로 표시된 것은 10건이다. 나머지 30건은 표지 없는 오답이다(§4).
- 재요청 경로 점검: 재요청 slot 모두 다음을 확인했다.
  - 첫 답에 UNREADABLE이 있었다.
  - 배정 variant를 변환 없이 보냈다(`variants/…`).
  - 토큰과 비용이 두 호출의 합과 정확히 같았다.

## 4. 탐색 관찰 (가설 판정에 쓰지 않음)

- **D′(개정 전 규칙)는 held-out에서 D와 비슷하다**: GPT-4o 79.2% 대 78.5%, Haiku 76.4% 대 77.1%.
  - calibration에서 GPT-4o D′가 크게 앞섰던 것(85.4% 대 75.0%)은 held-out에서 재현되지 않았다.
  - "창 없음 → 원본" 규칙은 clean·JPEG 조건에서 오히려 D보다 낮았다(GPT-4o clean D′ 83.3% 대 D 88.9%).
- **레이아웃**: v2(처음 보는 배치)에서 C·D가 크게 떨어진다.
  - GPT-4o D−A: 기존 −4.2%p, v2 −9.7%p
  - Haiku D−A: 기존 +5.6%p, v2 −13.9%p
  - 선택기가 v2에서 근거를 덜 덮는다(생성 단계, 창 찾은 것 중 근거 덮음: v2 30/48(62.5%) 대 기존 38/50(76%)).
- **영역**: 차트에서 A가 95.8%로 가장 높고, C·D의 손실이 크다(GPT-4o D 83.3%).
- **H3(C−B 음수)**: 선택만으로는 B(전체 1536 축소)보다 정확도가 떨어진다. GPT-4o는 B의 토큰이 A와 같아(RQ1 타일 규칙) B는 절감이 없다. C는 토큰을 31% 줄였지만 정확도를 잃었다.
- **표지 없는 오답**: C 오답 중 UNREADABLE로 표시되지 않은 것이 GPT-4o 30/40, Haiku 30/46이다. D는 표시된 경우만 구한다. 프로토콜·논문의 한계(Task 34 Q5)와 같은 관찰이다.

## 5. 사전 등록 이탈

- 없다. 실행 조건·동결 커밋·생성물 해시·분석 스크립트를 사전 등록대로 지켰다.
- 기록: 실행 래퍼 명령 끝의 `tail -1 파일1 파일2`가 이 환경에서 잘못된 옵션이라 종료 코드 1을 냈다. 실험 실행(`run.mjs`)은 두 공급자 모두 720/720 정상 종료했다. calibration의 종료 코드 1도 같은 원인이다.

## 6. 해석 한계

- 합성 이미지 3영역, 36 family, 두 모델이다.
- 선택기는 연구 코드(OCR 창 selector)다. 제품의 crop 도구는 영역을 호출자에게 받는다(선택기 결정 메모, PR #39).
- v2 레이아웃은 실험 3 held-out에서 모델에 노출된 적이 있다. 선택기는 그 뒤 바꾸지 않았다.
- 채점은 content-match다. 정답 문자열이 설명문 안에 있어도 정답으로 센다.
- GPT-4o 캐시 할인과 실험 3의 세션 비용은 이 실험(단일 호출)과 무관하다.
