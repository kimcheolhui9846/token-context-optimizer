이 부록은 사전 등록과 동결 설계를 재현 가능한 형태로 기록한다. 실행 결과, 결과 수치, 캐시 할인율 수치는 포함하지 않는다. 사전 등록과 동결 설계가 충돌하면 사전 등록을 기준으로 하며, 원고 수정 사항은 제안으로 남긴다.

## 1. 질문과 가설

**RQ3:** 다중 턴 에이전트 세션에서 원본 보존 발췌(플러그인)는 전체 유지와 compact에 비해 누적 청구 토큰과 과제 정확도를 어떻게 바꾸는가?

판정 기준(사전 고정)은 다음과 같다.

| 가설 | 비교 | 판정 기준(사전 고정) |
|---|---|---|
| H1 | S2 대 S0 | 세션 평균 내용 정확도 차이(S2−S0)의 95% 신뢰구간 하한이 −5%p보다 크고, 정가 기준 입력 토큰이 S0보다 적다 |
| H2 | S1 대 S0 | 늦은 회상 정확도 차이(S1−S0)의 95% 신뢰구간 상한이 0보다 작다 |
| H3 | S3 대 S1 | 늦은 회상 정확도 차이(S3−S1)의 95% 신뢰구간 하한이 0보다 크다 |
| H4 | 캐시 기준 대 정가 기준 | S2의 캐시 기준 비용 절감률이 정가 기준 절감률보다 작다(기술 통계로만 보고, 검정 없음) |

판정 표현은 `지지`, `지지 안 됨`, `성립`, `기술 통계`로 제한한다.

## 2. 동결한 설계와 조건

세션은 각 공급자 안에서 조건 간 같은 질문과 기본 응답 지시를 받는 8턴 고정 대본이다. 도구 조건에는 도구 사용 지시를 추가한다. 템플릿은 UI 디버깅, 문서 검토, 리포트 점검이다. 턴 1–3은 이미지·로그·이미지를 제시하는 즉시 문항, 턴 4는 교차 문항, 턴 5는 요지 문항, 턴 6–8은 앞선 이미지의 작은 글자와 로그 줄을 다시 묻는 늦은 회상 문항이다. S1과 S3의 compact는 턴 3과 턴 6 뒤의 고정 일정이다. 4,000 prompt-token 임계값 초과 턴 수는 보조 지표다.

| 조건 | 컨텍스트 처리 |
|---|---|
| S0 전체 유지 | 원본 이미지·로그 전문과 누적 대화를 계속 전달한다. |
| S1 compact 모사 | S0의 대화를 같은 모델의 고정 지시문으로 요약해 대체하며, 요약 뒤 이미지는 남기지 않는다. |
| S2 플러그인 | 아티팩트 카드만 전달하고 필요한 부분을 도구로 조회한다. |
| S3 플러그인 + compact | S2에 S1의 고정 일정 요약을 결합하고 아티팩트 ID를 남긴다. |
| S4 단순 축소 유지(보조) | S0과 같되 이미지를 긴 변 1536 이하, JPEG quality 75로 변환한다. |

S2와 S3의 도구는 `query_text_artifact`, `query_image_artifact`, `get_original_image`다. `query_text_artifact`는 실제 플러그인 MCP의 `query_artifact`를 호출하며, 당시 동작은 최고점 줄 하나 주변 한 구간이었다. `query_image_artifact`는 연구용 C1 OCR 선택기가 영역을 찾으면 `cropTransform`한 이미지와 썸네일(긴 변 512 이하, JPEG q75, GPT-4o detail low)을 함께 반환한다. 영역을 찾지 못하면 썸네일 없이 전체 이미지를 arm 변환(긴 변 1536 이하, q75)해 반환한다. `get_original_image`는 원본을 그대로 반환한다. 도구 왕복은 턴당 최대 3회다. 그 턴에 제시되었거나 마지막으로 조회한 이미지가 있고 응답에 대소문자 구분 없이 `UNREADABLE`이 포함되면 원본을 자동으로 한 번 제공하고 다시 답하게 한다. 이 재요청 호출에서는 도구 사용을 막으며, OpenAI 경로의 설정은 `tool_choice: none`이다. 도구 결과 이미지는 턴 3·6 뒤 비우고 텍스트 흔적은 남긴다.

compact는 공개 규칙을 재현한 실험용 모사다. Task 40의 skill 규칙이나 Claude Code·Codex 제품 compact의 내부 동작 또는 성능을 주장하지 않는다. temperature는 0이다. GPT-4o는 compact를 제외한 모든 호출 60토큰, compact 호출 400토큰이다. Haiku는 도구 경로 512토큰, 그 밖의 일반 응답 60토큰, compact 호출 400토큰이다. 요약은 250단어 미만이다.

## 3. 데이터

개발 3세션, calibration 6세션, held-out 24세션이다. 템플릿별 held-out 8세션은 기존 레이아웃 4세션과 전용 새 레이아웃 변형 4세션으로 나누고, 기존·새 레이아웃별로 보고한다. seed 대역은 각각 5000번대, 6000번대, 7000번대다. 파일럿 세트(101–606, 2000번대, 3000번대)와 실험 2 family(8000번대, 9000번대)는 겹치지 않는다. manifest `research/out/sessions/heldout/sessions.json`은 재생성 시 동일하며 SHA-256은 `b88f64e3df671fff20a8562f7fbe1ba929b94f56d842e452b72d0cfb979d5da2`다. 개발·calibration은 설계를 정하는 탐색 단계이며 그 결과 수치는 이 부록에 옮기지 않는다.

seed 분리의 근거는 `research/src/sessions.mjs:16–17`과 `research/src/families-exp2.mjs:6`이다. 새 변형은 요소 배치, 글자 크기 분포, 표·카드·범례 위치를 바꾸되 질문 유형과 정답 생성 규칙은 유지한다. 변형 이미지는 어떤 모델에도 미리 보내지 않는다.

## 4. 공급자

주 분석은 `gpt-4o-2024-11-20`, 보조 분석은 `claude-haiku-4-5-20251001`이다. GPT-4o의 기본 detail은 high다. 전체 개요는 긴 변 512 이하와 detail low를 사용한다. Haiku에는 detail 설정이 없으므로 긴 변 512 이하 이미지 자체를 보낸다. Haiku 공식 SDK 도구 경로는 개발 세트로 점검한 뒤 동결했고, 점검 결과를 보고 compact 일정과 도구 왕복 상한을 바꾸지 않았다. 도구 경로 출력 상한 512토큰은 하네스 커밋 `2331e88`에 있다.

## 5. 지표와 분석

주 지표는 세션 평균 내용 정확도다. yes/no·on/off는 해당 단어가 있고 반대 단어가 없으면 맞음, 숫자는 단독 일치, 월은 약어를 허용한다. 보조 지표는 늦은 회상·교차·요지·즉시 정확도, 정가 입력 토큰, 캐시 기준 비용, 호출 수, 임계값 초과 턴 수, `UNREADABLE` 수, 원본 재요청 수다. 도구 왕복과 compact 요약 호출을 포함한 누적 usage를 센다.

분석 단위는 세션이며, 같은 세션을 모든 조건에 적용해 차이를 짝지어 계산한다. 신뢰구간은 세션 단위 bootstrap 10,000회, 기준 seed `20261015`, percentile 95%로 계산한다. 실패와 타임아웃은 오답으로 센다. 실행하지 못한 세션은 `not_started`로 따로 보고하고, 완료 연구로 보고하지 않는다. 세션 제외는 하지 않으며 오류가 난 세션도 분모에 남긴다. 가설 밖의 비교는 탐색 결과로 표시한다.

구현상 H1·H2·H3은 기준 seed에서 각각 +0·+1·+2인 `20261015`, `20261016`, `20261017` 스트림을 사용한다. CI는 비교할 두 조건의 결과가 모두 있는 세션으로 짝을 구성한다. 실패·타임아웃은 결과 파일 안에서 오답으로 남아 분모에서 빠지지 않는다. 결과 파일이 없는 세션·조건 조합만 `not_started`로 별도 기록하며, 하나라도 있으면 해당 실행을 완료 연구로 보고하지 않는다(`research/src/session-analyze.mjs:52–78`).

## 6. 캐시 기준 비용

정가 기준과 캐시 기준 비용을 모두 보고한다. 캐시 기준 비용은 공급자가 보고한 캐시 토큰과 확인된 공식 할인율로 계산한다. 할인율을 확인하지 못하면 가정값과 `[검증 필요]`를 함께 보고한다. 이 부록에는 할인율 숫자나 실행 결과를 적지 않는다.

## 7. 하지 않는 것과 한계

held-out 결과를 보고 설계·채점 규칙·margin을 바꾸지 않는다. 변경이 필요하면 새 held-out 세트로 다시 등록한다. 오류 세션도 분모에 남긴다. `not_started`는 별도 상태다. 대본 세션이므로 실제 자율 에이전트로 일반화하지 않는다. RQ2는 범위 밖이다.
