## 4. 그림 F1–F4

순서대로 확인한다.

1. **기초 수치.** 그림 생성 중 matplotlib 객체에서 좌표·막대 높이·오차 막대 끝점을 기록한다. 같은 원자료에서 독립 계산한 값과 비교한다. 허용 오차는 절댓값 1e-9다.
   - F1: `rows.jsonl`의 PNG 격자 행에서 공급자별(GPT-4o high, Haiku) 비율 4종 × 긴 변 7개의 청구 토큰.
   - F2: 재생성 `graded.jsonl`의 arm별 family 평균 정확도와 질의당 평균 입력 토큰, family bootstrap 95% 구간(10,000회, seed 20261016).
   - F3: 세션 평균 정확도와 세션당 평균 입력 토큰(÷1,000), 세션 bootstrap 95% 구간(10,000회, seed 20261015).
   - F4: 조건별 늦은 회상 정확도와 같은 방식의 구간.
2. **축과 표식.** 축 제목, 눈금 라벨, 축 범위, 척도(선형), 범례 항목, 계열 수, 색, 표식 모양, 점 라벨이 기준 정의와 같다.
3. **렌더.** 재생성 PNG를 기준 커밋 PNG(원고 링크 파일)와 비교한다.
   - 바이트 동일 또는 해독한 RGBA 배열 동일 → 렌더 일치.
   - 다르면 크기가 같고, 다른 픽셀 비율 ≤ 0.5%, 평균 절대 차이 ≤ 2/255이며 1·2단계가 모두 통과한 경우에만 허용 범위 안으로 본다. 폰트·안티에일리어싱 차이를 위한 범위다.
   - 크기가 다르거나 범위를 넘으면 MISMATCH다.
4. **육안 대조.** 독립 마일스톤 검토자(Claude Opus 5.5)가 재생성 PNG와 기준 PNG를 나란히 보고 축 제목, 눈금, 범례, 계열 수·색·표식, 오차 막대, 점 라벨 위치, 잘림·겹침을 확인한다. 하나라도 다르면 MISMATCH로 기록하고 이유를 적는다.

필수 PDF는 F1–F4의 생성 출력 네 개다. `all`과 `compare`는 각 파일의 한 페이지를 pypdfium2 5.15.1로 72 dpi에서 렌더링한다. 기준은 입력 매니페스트가 검증한 해당 도판의 PNG다. 두 이미지의 종횡비 차이가 2%를 넘으면 실패한다. 렌더 전 각 축은 4,096 pt 이하, 올림한 너비와 높이의 곱은 800만 픽셀 이하여야 한다.

흰 배경 RGB에서 두 이미지를 기준 PNG의 종횡비와 너비 256픽셀에 맞춰 LANCZOS로 축소하고 반경 1픽셀 가우시안 필터를 적용한다. 정규화한 RGB 평균 절대 차이는 0.04 이하, 잉크 영역은 양쪽 각각 0.5% 이상, 두 잉크 영역의 교집합/합집합은 0.70 이상이어야 한다. 잉크는 RGB 중 한 채널 이상이 223 미만인 픽셀이다. 작은 글자·개별 점의 정확성은 과학 판정과 육안 대조에서 별도로 확인한다.

과학 판정 7/7이어도 필수 PDF가 누락되거나 열리지 않거나 도판 대조에 실패하면 `deliveryPass`가 false가 되고 명령은 코드 1로 끝난다. `requiredPDFs`에서 파일명과 원인을 볼 수 있다. PDF 해시는 인도 파일 식별에 쓴다.

## 5. 실행 조건

- 의존성 설치(Python 가상환경의 고정 버전)와 오프라인 재생성을 나눈다. 재생성 단계는 네트워크 차단 preload(Node)와 `sitecustomize`(Python)를 적용하고, 공급자 키 환경변수를 제거한다. 차단은 해당 프로세스와 그 하위 프로세스 범위이며 시스템 방화벽은 바꾸지 않는다. 시작 전에 음성 대조(차단이 실제로 거부하는지)를 확인한다.
- 패키지 입력은 읽기만 한다. 출력은 존재하지 않던 별도 경로에 쓴다. 실행 전후 패키지 파일 해시가 같아야 한다.
- 빈 출력 폴더에 기준 이미지나 집계표를 복사해 성공으로 처리하지 않는다. 기준 파일은 `expected/`에만 있고 생성기 작업 폴더에 들어가지 않는다.
- 손상·누락 입력은 매니페스트 검증에서 실패해야 한다. 이를 한 번 확인한다.
