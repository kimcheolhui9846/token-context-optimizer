# 원고의 주장과 측정 근거

대상은 [논문 초안 #112](https://github.com/kimcheolhui9846/token-context-optimizer/pull/112)의 [e1e535186 원고](https://github.com/kimcheolhui9846/token-context-optimizer/blob/e1e53518626768d0b18380f7f59968a86f830e47/docs/research/image-first-paper-draft.ko.md)다. 원고 행과 근거 파일은 같은 커밋에 고정했다. 원고가 바뀌면 변경된 주장과 수치를 다시 대조한다.

**판정 기준** · 정확도 차이는 퍼센트포인트(%p), 절감률은 기준 조건 대비 비율(%)이다. 비열등성은 짝 차이 95% 신뢰구간(CI)의 하한이 −5%p보다 크고 입력 토큰도 줄어야 지지된다. 실험 2의 재표집 단위는 원본 family, 실험 3은 세션이다. 그림의 arm별 오차막대와 표의 짝 차이 구간은 추정량이 다르다.

**실행 버전** · 실험 2는 사전 등록 개정 1 뒤 동결한 dbf4f6b를 사용했다. 실험 3은 사전 등록 ec6d534, 하네스 2331e88, 분석 7d2425e를 출발점으로 한다. 중단된 시도와 재실행은 VII에서 구분한다. [실험 2 실행 기록](https://github.com/kimcheolhui9846/token-context-optimizer/blob/e1e53518626768d0b18380f7f59968a86f830e47/research/results/exp2-heldout/README.md) · [실험 3 실행 기록](https://github.com/kimcheolhui9846/token-context-optimizer/blob/e1e53518626768d0b18380f7f59968a86f830e47/research/results/s3-heldout/README.md)
