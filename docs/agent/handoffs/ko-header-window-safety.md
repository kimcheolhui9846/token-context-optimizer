# 한국어 표 머리글 창의 신규 숫자 노출 비교

- Tier E. #158의 복원 원본 3개에서 대조 3장과 변형 12장을 비교했다. [사전등록](../../../research/plans/2026-11-26-ko-header-window-safety.md) · [결과, 원본 및 재현법](../../../research/results/ko-header-window-safety/README.md)
- 사용자가 전체 폭과 두 제목 창 비교를 승인했다. GPT-6.2 Sol은 창 조립과 단위 시험, Claude Code Sonnet `claude-sonnet-5-5`는 새 자료 생성기와 시험을 맡았다. 표시기에는 별관 위치나 골드가 전달되지 않는다.
- Claude Code `claude-opus-5-5` 계획 재검토 PASS. 배치 무효 기준, 고정 기하 분석 분리, 선택 계약, 파일별 책임·운영 규칙 분리를 반영했다.
- 과학 코드·기준 `f335212`을 원격 Draft에 먼저 올렸다. 첫 시도는 상위 입력기가 18건만 받아 OCR 전 중단됐다. `b18b337`의 실행 어댑터가 원본 해시를 대조하고 입력 개수 검사 한 곳만 15로 맞춘다.
- 사전등록 판정은 실제 OCR와 위치 고정 모두 미확정이다. 실제 경로 5/15 적용(대조 3 + 무효 배치 2), 유효 위험 0. 위치 고정에서 유효한 6장 모두 전체 폭은 별관 숫자를 노출했고 두 창은 막았다. 아래쪽 6개 배치는 구분선 겹침으로 무효이며 자료에 유지했다.
- 두 로컬 CPU 실행의 공개 데이터 148개가 동일했다. 독립 검산기로 30개 화면 세트와 글자별 계수를 재구성했다. 두 독립 표본 수가 아니라 같은 원본 3개를 두 방식으로 평가했다.
- Claude Code `claude-opus-5-5` 마일스톤 PASS. 중대 0, 경미 2. 별도 셀·픽셀 검산의 불일치 0. 격리한 리뷰 자료의 상대 경로를 복원한 후 Opus가 32/32 시험 통과를 재확인했다.
- 유료 여부를 검증하지 못한 별도 Argon API는 실행하지 않았다. 합성 문서에 대한 외부 추론은 수행하지 않았다.
- 제품의 기존 Windows 파일 교체 시험이 최초 병렬·단일 작업자 전체 회귀에서 실패했고, 해당 시험 파일 단독 재실행은 4/4 통과했다. 최종 회귀 결과는 Draft PR 검증 기록을 참고한다.
- 로컬 WBS에는 실행계획의 R09 현재 증거와 기존 운영 작업의 비고에 각각 한 건을 추가했다. 정리 규칙은 별도의 계획 #159·구현 #161이며 기존 연구 상태 및 논문 범위는 유지했다.
