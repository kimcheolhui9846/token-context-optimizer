## Findings 및 경계 판정
- WBS `Findings` 시트의 기존 ID는 N-41(확인필요), N-42/N-43/N-44(미해결·P09 이월), N-45(해결·Note)와 대조했다. P07에서 새 ID를 만들거나 기존 ID를 중복 등록하지 않는다.
- N-41은 P06의 오류명·로그·4/4·P08 책임만 인용하며 P07 원인 확인으로 승격하지 않는다. 경로/동시성 실패 근거는 P06 보관 문서·로그 범위로 제한한다.
- 이미지 metadata store의 개수·용량·퇴출 방식은 제품 동작 변경 없이 별도 정책 결정 항목이다. 같은 경로·바이트·profile 재색인은 같은 ID를 내고, 없는 ID는 inspect에서 `unknown_artifact_id`, crop/overview에서 `artifact_not_indexed`가 된다. 텍스트 256 MiB 추정 bound/LRU는 비교 자료일 뿐 이미지 정책의 독립 기대값이 아니다.
- 직접 API의 omitted `allowedRoots` cwd 기본값과 built MCP의 `TCO_ALLOWED_ROOTS` 요구는 서로 다른 경계로 기록한다. 실행한 테스트 assertion은 현재 후보의 관찰이고, 공개 문서 문장은 공개 보장 범위로만 쓴다.
