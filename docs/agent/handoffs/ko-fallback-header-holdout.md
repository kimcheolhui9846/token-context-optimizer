- 과학적 고정점은 `59b3c6b`이다. 최초 렌더 뒤 Windows 경로 따옴표 처리로 OCR 전 중단됐다. 실행기만 수정한 `0fc0cb5`에서 동일 렌더를 확인하고 OCR부터 판정까지 두 번 실행했다.

- 공개 산출물 106개가 두 실행에서 바이트 단위로 일치했다. 별도 Python 검산기가 18쌍의 이미지 구성, 단서 잉크, 다른 기록 신규 노출과 최종 판정을 재현했다. 렌더러의 위치 주석은 공유한다.
- 기준 제품 검사에서 같은 파일을 교체하는 경쟁 조건 시험이 병렬 실행 1회 실패했다. 소스 변경 없이 해당 파일을 단독 재실행해 4/4 통과했다.
