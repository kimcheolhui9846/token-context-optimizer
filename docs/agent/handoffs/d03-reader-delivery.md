## 판정과 검증

- **RED**. 기존 원고의 상대 참조 14곳이 독자 위치에서 끊겼다. F1 PDF를 지우거나 11바이트 파일로 바꿔도 구판 `compare`는 7/7과 종료 0을 반환했다.
- **GREEN**. 새 독자 명령은 한 페이지인 필수 PDF를 각각 열고 대응하는 기준 PNG와 비교한다. `report.json`에는 `all`의 판정, `compare.json`에는 `compare`의 최신 판정이 남는다. `requiredPDFs`에 그림 ID·경로·원인을 기록한다. [판정 기준](../../research/d03-reproduction-rules.md)
- **반례**. 누락, 11바이트, 절단, 백지, 다중 페이지, 도판 바꿈, 같은 크기의 F2·F3 바꿈에서 과학 7/7과 PDF 실패가 함께 기록되고 종료 코드는 1이었다. 복원 후 0. 생성 단계에서 F1이 빠진 상황도 `all`에서 7/7·PDF 3/4·종료 1을 확인했다.
- **재현**. 판본별 두 빌드의 SHA-256 일치. 두 ZIP의 격리 실행에서 표·그림 7/7, 필수 PDF 4/4, 보조 결과 21/21, 캡션 24/24 및 가드가 적용된 오프라인 12단계를 확인했다. 기존 ZIP 세 개를 각각 재빌드해 기존 SHA-256과 대조했고, 원자료 252개의 경로와 지문을 확인했다.
- **환경**. Windows x64·CPython 3.12에서 검증했다. 사용자가 승인한 pypdfium2 5.15.1은 버전 목록과 Windows wheel 해시 잠금에 포함했다. 해당 wheel을 네트워크 없이 격리 경로에 설치해 실제 F1 PDF를 렌더링했다.
- **회귀**. D03 검사 64개 통과. 빌드·타입 검사·MCP 스모크·플러그인 검사·제품 테스트·벤치마크 통과. 제품 테스트 단일 워커 전체 실행 4,639개 통과, 5개 건너뜀.
- **범위**. 네 도판의 전체 화면 유사도를 검사한다. 작은 글자·개별 점의 차이에는 과학 판정과 육안 대조를 함께 사용한다. 다른 플랫폼과 외부 배포는 별도 검증 대상이다.
- **제품 테스트 관찰**. 이미지 파일 교체 테스트 한 건이 두 차례 전체 실행에서 예상한 `source_changed` 대신 `read_failure`를 반환했다. 이 작업에서 해당 플러그인 경로는 변경하지 않았고, 기존 파일을 단독 세 차례 실행하면 모두 통과했다. 원인은 확인되지 않았다.

## 독립 검토와 인계

Claude Opus 5.5의 계획 검토 및 최종 마일스톤 PASS. 차단·중대 지적 0건. 독립 실행에서 두 쌍의 새 빌드와 세 동결 ZIP의 바이트 일치, 독자 링크, 실제 CLI의 실패·복원 및 JSON·Markdown 결과를 대조했다. 검증 지문 `ba4699478eea0306`. 정상 네 도판의 평균 절대 차이는 0.01153–0.01764(허용 상한 0.04), 잉크 영역 교집합/합집합은 0.84029–0.91991(허용 하한 0.70)이었다. 주 세션은 재생성 PDF 네 장을 렌더링해 직접 확인했다.
