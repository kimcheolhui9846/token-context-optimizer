# 한국어 표 실험과 심사본 주장 대조

**Tier D · 문서 편집 검토.** D02 심사본과 공개 원고의 관련 문구를 찾고, W4의 열 선택, W5의 표시 재생, 독자 판독 절차가 각각 뒷받침하는 주장을 구분한다. [근거표와 권장 문안](../../research/ko-table-manuscript-evidence.ko.md)

- 기준은 D02 최종 8쪽 PDF와 이 PDF에 대응하는 공개 초안이다. 자료의 고정 버전은 근거표에 연결했다.
- 원고의 관련 문구를 쪽별로 직접 대조하고 실험 결과의 측정 대상, 원고 문구의 편집 여부, 한계 절의 삽입 위치를 기록했다. 심사본과 개인 응답은 공개 대상에서 제외했다.
- 최종 PDF의 SHA-256과 공개 초안의 Git blob이 D02 기록과 일치했다. 일곱 행의 원문 발췌 아홉 곳을 PDF 쪽과 공개 초안 행에서 확인했고, 고정 출처 열여덟 곳의 파일·행과 문서 diff를 직접 대조했다. `git diff --check`를 통과했다. 제품 코드나 새 실험 수치를 다루지 않는 문서 작업이다.
- 독립 검토 자료는 선행 연구 결과에 적용된다. 이 근거표 자체에 대한 별도 Claude 검토 파일은 전달되지 않았다.
- 다음 결정은 저자가 Ⅶ장 문안의 채택 여부를 정하는 것이다. 채택 시 출처와 8쪽 조판을 재확인한다.
