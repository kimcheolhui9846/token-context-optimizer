# 한국어 표 공개 모의 판독의 판단 불가 사례

**Tier E · 사후 사례 분석.** 공개 시연 AI가 관리자 자료를 보았다고 응답한 상태에서 판독을 보류한 일곱 위치를 분석한다. 공개 패킷과 시연의 18개 응답으로 범위를 한정했다. [결과표와 재현법](../../research/evidence/ko-mock-abstention-audit/README.md)

- 기준은 #155의 `2efecd8544cab261f56bc68b204bdb5cd44a5fb3`이다. 선택 결과를 이미 안 상태에서 공개 모의 응답과 위치·방법·패킷 해시를 `482ab50`에 먼저 고정했다.
- 모든 위치의 원본·W1·W4·W5에서 각 열 제목과 값, 행 이름을 먼저 측정하고 ‘판단 불가’ 여부를 마지막에 결합했다. 최초 코드화한 표시 손실을 응답의 인과 효과로 해석할 수 없다.
- 관찰은 W4에서 제목이 잘리고 W5에서 다시 표시된 다섯 건, W1이 머리글 없는 최초 창을 유지하고 W5도 그 창을 반환한 두 건이다. 사람이 다른 방식에서 답을 바꿀지는 측정하지 않았다.
- 분담은 Sol이 픽셀 분석기와 단위 시험, Claude Sonnet 5.5가 정적 비교표 생성기 초안, 주 세션이 원자료 독립 검산, 화면 확인, 보고서 및 통합 검증을 맡았다.
- Claude Opus 5.5 계획 검토에서 결과 선별, 비눈가림 및 노출 기록, 사후 동결, 육안 QA 범위, 사람 성능 미측정, 픽셀 판정 기준을 보완했다. 보완 계획은 PASS였다.
- 공개 모의 자료를 새 폴더에 재생성했다. 공개 원본 대조는 54개 일치, 기록된 줄바꿈 예외 1개, 불일치 0개였다. 독립 계산에서 360개 가시성 판정이 일치했고 웹 브라우저에서 비교 화면 7개와 PNG 28개를 확인했다.
- 선택기, 제품 코드, 논문은 이번 변경 범위에서 제외했다. 후속 후보는 W4 미적용 시 최초 창에서 머리글이 빠진 경우의 처리다. 별도 자료로 검증한 뒤 제안한다.
- Claude Opus 5.5 결과 검토 PASS. 차단·주요 0, 경미 2. 좌표 주석을 공유한다는 검산 한계를 명시했고, 양쪽 출력 파일의 전체 집합과 29개 개수까지 재대조했다.
- 검증은 실제 공개 자료를 지정한 Python 시험 24개, 연구 JS 173개·Python 15개 통과였다. 작업 초기 연구 의존성 미설치로 sharp 관련 시험이 실패했고 npm ci 후 통과했다. 제품 빌드·타입·MCP·패키지·벤치마크 통과, 제품 테스트 4,639 통과·5 건너뜀(작업자 4개)이었다.
